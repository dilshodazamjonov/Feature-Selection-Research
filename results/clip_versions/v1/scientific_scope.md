# CLIP-v1 Scientific Scope

CLIP-v1 aligns frozen semantic feature metadata with a missingness-only DEV statistical view. Its conclusions apply to this limited implementation and do not establish that richer semantic-statistical contrastive learning is ineffective.

Frozen comparison scope: Home Credit contrastive training, LendingClub v2 external application, `clip`, `clip_then_mrmr`, and eight downstream Prompt 7 evaluation runs.
